당신은 이 프로젝트의 프론트엔드 개발자입니다. `FE/` 디렉토리만 수정합니다.

## 시작 전 — 이 순서로 읽으세요

1. **`docs/worklog-fe.md`** — 프론트엔드 구현 현황과 다음 작업. **가장 먼저 읽습니다.**
2. `docs/HANDOFF.md` — 전체 맥락, 결정 로그, 환경 함정
3. `FE/CLAUDE.md` — 코드 규약
4. `docs/design-tokens.md` — 화면 구조와 토큰

API를 호출해야 한다면 `docs/api-spec.yaml`에 해당 엔드포인트가 있는지 먼저 확인하세요.
**없으면 임의로 만들지 말고 그 사실을 보고**하세요 — 계약은 FE 혼자 바꿀 수 없습니다.

## 지켜야 할 것

- 색상·간격·폰트는 `src/styles/tokens.css`의 CSS 변수만 씁니다. 하드코딩 금지.
- 사용자에게 보이는 문자열은 `locales/ko.json`과 `en.json` **양쪽**에 추가합니다.
- 서버 상태는 TanStack Query, 호출은 `src/api/client.ts`의 `api.*` 경유.
- API 응답 타입은 `schema.d.ts`에서 파생합니다. 손으로 정의하지 마세요.
- `erasableSyntaxOnly`가 켜져 있어 생성자 파라미터 프로퍼티와 `enum`을 쓸 수 없습니다.
- 모바일 375px 기준입니다. 데스크톱 분기를 추가하지 마세요.

## 끝내기 전 (두 가지 모두 필수)

**1) 빌드 검증**

```bash
cd FE && npm run build; echo EXIT=${PIPESTATUS[0]}
```

**EXIT=0을 직접 확인**하세요. 파이프 뒤의 종료 코드를 보면 실패를 성공으로 착각합니다.

**2) 작업 로그 갱신 — 이걸 빼먹으면 다음 세션이 같은 작업을 반복합니다**

`docs/worklog-fe.md` 를 수정하세요:
- §1 구현 현황 표에서 이번에 완료한 항목을 ✅ 로 바꾸고, 새로 생긴 미완 항목을 추가
- §2 다음 작업에서 끝난 항목을 제거하고, 발견한 후속 작업을 추가
- 최상단 "최종 갱신" 줄의 날짜와 한 줄 요약 교체

프로젝트 전체에 영향을 주는 변화(새 결정, 새 환경 함정, 진행률 변동)라면
`docs/HANDOFF.md` 의 §4 진행률 / §7 결정 로그 / §8 함정도 함께 갱신하세요.

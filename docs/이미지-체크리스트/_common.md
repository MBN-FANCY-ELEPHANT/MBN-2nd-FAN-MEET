# 공용 이미지 체크리스트 (아티스트 3명이 함께 씁니다)

응원 팁과 굿즈는 **내용이 아티스트를 타지 않습니다** ("멜론 스밍하는 방법", "공식 응원봉").
그래서 3명이 같은 그림을 써도 어색하지 않고, 만들 장수가 3분의 1로 줄어듭니다.

- 파일이 없으면 자동으로 `/example_thumb.png` 로 폴백합니다
- `public/` 파일은 캐시가 강합니다. 교체 후 안 바뀌면 **Ctrl+Shift+R**

---

## 응원 팁 썸네일 5장 — `data.sql` 의 `tip.thumbnail_url`

| ☐ | 파일명 | 크기 | 카테고리 | 예시 제목 |
|---|---|---|---|---|
| ☐ | `tip-streaming.png` | 400×225 (16:9) | STREAMING | "멜론 스밍하는 방법" |
| ☐ | `tip-vote.png` | 400×225 | VOTE | "트롯가왕 투표 방법" |
| ☐ | `tip-ticketing.png` | 400×225 | TICKETING | "콘서트 티켓팅 준비물" |
| ☐ | `tip-cheer.png` | 400×225 | CHEER | "응원봉 사용 가이드" |
| ☐ | `tip-fanclub.png` | 400×225 | FANCLUB | "공식 팬클럽 가입 안내" |

> 아티스트당 팁이 6건인데 6번째는 위 5장 중 하나를 재사용합니다
> (성리=CHEER, 이찬원=VOTE, 박서진=FANCLUB — 전부 "해외 팬" 안내글).

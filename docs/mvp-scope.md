# MVP 범위 및 컷 라인

해커톤 심사는 **완성도 있는 하나의 흐름**이 절반만 된 열 개 기능을 이깁니다.

**최종 갱신:** 2026-08-07 · Figma 확정본(13화면) 반영, 골든 패스 재정의

---

## 1. 데모 골든 패스 (이것만은 반드시 동작)

심사 시연 대본과 1:1로 대응합니다. 이 경로에 있는 기능이 **최우선**입니다.

```
① HOME 진입
   → 스타 팬덤 공간, 다가오는 일정, 아카이브(기사·영상), 모집 중 모임이 한 화면에

② 마이크 버튼 → 음성으로 질문
   → "그.. 우리 임영웅이.. 콘서트가 언제야"  (구어체 그대로 실시간 표시)
   → 비엔이가 DB의 Schedule을 근거로 답변 + 딥링크
   → 범위 밖 질문("오늘 날씨 어때?")을 해보이며 스코프 제한을 시연

③ 뉴스 상세 진입 → AI 분석 패널
   → 기사를 AI가 항목별로 분석한 결과가 즉시 렌더 (사전 생성이라 대기 없음)

④ 댓글 화면
   → 한국 · 미국 · 일본 유저의 댓글이 국가 배지와 함께 섞여 있음
   → 번역 버튼 탭 → 외국어 댓글이 내 언어로 전환
   → ★ "글로벌 팬덤"을 눈으로 증명하는 구간

⑤ 모임 상세 → 참여 신청
   → 34/40 → 35/40 즉시 반영 + 진행바 갱신 + Toast

⑥ 언어를 EN으로 전환
   → UI 전체 영문화 + 비엔이도 영어로 응답 + AI 분석도 영어
```

②와 ④가 이번 디자인에서 새로 생긴 핵심 구간입니다.
⑥이 주제("**글로벌** 트롯 팬덤 플랫폼")를 증명합니다. 절대 빼지 마세요.

> ⚠️ **②의 최대 리스크는 마이크 권한**입니다. 리허설에서 미리 허용해 두고,
> 거부되어도 텍스트 입력으로 이어갈 수 있는 폴백을 반드시 구현하세요 (`ai-stack.md` §2).

### 컷 — 이번 해커톤에서 하지 않음

- ❌ **실시간 채팅 / WebSocket** — AI 도우미가 "실시간 소통" 서사를 담당
- ❌ **결제 / 송금** — 법적·보안 리스크. 모임 비용은 표시 전용
- ❌ **실시간 라이브 스트리밍** — LIVE는 **정적 배지 표시까지만**. 동시 시청자 수는 시드 값
- ❌ 자체 영상 스트리밍 (YouTube 임베드로 대체)
- ❌ 다중 스타 팬덤 공간 (스키마만 준비, 데이터는 1명)
- ❌ 정교한 인증 — 회원가입·비밀번호·소셜 로그인 없음. **간이 데모 로그인만**
- ❌ 커뮤니티 게시판 — 디자인에 화면 없음. `Post` 엔티티는 미사용
- ❌ 팬 등급제, 웹 푸시, 데스크톱 전용 레이아웃

## 3. "스타와 팬의 실시간 소통" 주제 대응

기획서 10장에서 지적된 대로, 현재 와이어프레임은 **팬↔팬** 소통에 가깝습니다.
주제의 "스타↔팬"을 실제 스타 참여 없이 충족시키는 현실적 방안:

| 방안 | 구현 비용 | 채택 |
|---|---|:-:|
| **음성 AI 도우미 "비엔이"** — 스타 콘텐츠 기반 대화 | 중 | ✅ P0 |
| **AI 분석** — 스타가 나온 기사·방송을 AI가 해설 | 중 | ✅ P0 |
| **글로벌 댓글 + 번역** — 전 세계 팬이 같은 콘텐츠에서 소통 | 중 | ✅ P0 |
| **스타 공식 메시지** — 관리자가 등록, HOME 상단 노출 | 낮 | ⚪ P2 |
| 라이브 방송 댓글 연동 | 높 | ❌ |

> AI가 스타를 **사칭하지 않는다**는 원칙은 유지합니다 (기획서 5-2 필수 정책).
> 도우미는 **"MBN AI 도우미 비엔이"** 로 자기소개하며, 이 점이 오히려 심사에서
> **책임 있는 AI 설계**로 평가받을 수 있습니다.
>
> 답변 범위도 MBN·트롯·플랫폼 데이터로 **의도적으로 제한**합니다. 범용 챗봇이 아니라는
> 점을 시연에서 직접 보여주는 것이 신뢰도에 유리합니다.

## 4. 해결된 이슈 (재논의 불필요)

| # | 이슈 | 결정 |
|---|---|---|
| 1 | `PLAY` 메뉴명이 모호 | PLAY 유지. 섹션명을 **성지순례 / 응원하기**로 구체화 |
| 2 | HOME과 COMMUNITY의 모임 중복 | HOME=추천 4건 2열 그리드 / COMMUNITY=전체 세로 리스트 |
| 3 | 언어 전환 시 콘텐츠 번역 범위 | UI 문자열 7종 + **댓글 단위 번역 버튼**(P0로 승격) |
| 4 | 영상 저작권 | **YouTube 임베드**만 |
| 5 | 모임 사기 방지 | `official` 배지 + 상세 화면 고정 경고문 + **금전 거래 미중개 고지** |
| 6 | AI 진입점 | **마이크 FAB 단독.** 검색바 AI 모드는 디자인에서 삭제됨 |
| 7 | AI 벤더 | **OpenAI 단일화.** TTS·STT 때문에 어차피 필요 (`ai-stack.md` §1) |
| 8 | AI 분석 생성 시점 | **사전 생성 + DB 캐싱.** 요청마다 호출하지 않음 |

## 5. 진행 순서

**1) 계약 확정** ✅ 완료 — `design-spec.md` · `api-spec.yaml` · `design-tokens.md` · `component-map.md` · `ai-stack.md`

**2) 기반 정리** (여기부터 시작)
- BE: `Archive → Content` 재정의 + 시드 재작성 ← **선행 필수**
- FE: `tokens.css` 실측값 교체 + 375px + 언어 7종 ← ①과 병렬 가능

**3) 도메인 확장** (BE/FE 병렬)
- BE: Comment · Reaction · Subscription · 간이 인증 → AiAnalysis → Chat
- FE: HOME → COMMUNITY → 모임 상세 → 뉴스/영상 상세 → 댓글 → 음성 오버레이 → PLAY

**4) 마지막 날**
- 시드 날짜 갱신 (과거가 되면 "다가오는 일정"이 비어 보입니다)
- 시연 리허설 3회. **마이크 권한 사전 허용** + 텍스트 폴백 확인
- 네트워크 실패 시 화면이 멈추지 않는지 확인

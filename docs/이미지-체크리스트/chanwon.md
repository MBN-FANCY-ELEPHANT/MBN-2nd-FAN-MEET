## 영상 URL (이미지 아님 — `data.sql` 에서 교체)

✅ **4건 + 무대 영상 모두 실제 링크로 반영 완료** (iframe 재생 확인, 재생시간 교정).

| ☐ | 위치 | 영상 |
|---|---|---|
| ☑ | `artist_stage` id=2 | 음성 "이찬원 무대 보여줘" 의 답 |
| ☑ | `content` id=22 | 신곡 [진심 한 줄] 최초 라이브 무대 |
| ☑ | `content` id=23 | 한일톱텐쇼 본선 무대 생중계 ⚠️ LIVE 배지 |
| ☑ | `content` id=25 | 0812 이찬원 팬미팅 하이라이트 |
| ☑ | `content` id=27 | 이찬원 [편지] 무대 직캠 |

바꾸는 값은 `https://www.youtube.com/embed/<영상ID>` 형식입니다.
**썸네일(`thumbnail_url`)은 건드리지 마세요** — 같은 ID 의
`https://i.ytimg.com/vi/<영상ID>/maxresdefault.jpg` 를 가리키게 돼 있어 자동으로 따라옵니다.
(HD 업로드가 아니면 `maxresdefault` 가 없는데, 그때는 `hqdefault` 로 자동 폴백합니다.)

⚠️ **임베드가 막힌 영상은 오류 없이 검은 화면만 남깁니다.** 반드시 **iframe 안에서**
재생을 확인하세요 — 주소창에 embed URL 을 직접 열면 정상 영상도 오류 153 이 나서
검증이 무의미합니다.

## 저장 위치

```
FE/public/artists/sungri/goods/
FE/public/artists/chanwon/goods/
FE/public/artists/seojin/goods/
```

- 파일이 없으면 자동으로 `/example_thumb.png` 로 폴백합니다 (깨진 아이콘 안 뜸)
- **확장자는 자유**입니다 (`.jpg`/`.png` 섞여도 됨). 대신 파일을 추가·삭제·개명하면
  **`FE/src/data/goods.ts` 의 `GOODS_FILES` 배열도 같이 고쳐야** 합니다 —
  `public/` 은 번들러가 훑지 않아 파일 목록을 자동으로 알아낼 방법이 없습니다
- `public/` 은 캐시가 강합니다. 교체 후 안 바뀌면 **Ctrl+Shift+R**

## 품목·가격을 바꾸려면

`FE/src/data/goods.ts` 의 `buildGoods()` 안 배열만 고치면 3명 모두에 반영됩니다.
아티스트마다 **다른 품목**을 넣고 싶으면 `GOODS_BY_ARTIST` 에서 `buildGoods()` 대신
배열을 직접 쓰세요.

## ⚠️ id 대역

상세 링크(`/fanspace/goods/:id`)가 id 로 찾으므로 **전체에서 유일**해야 합니다.

| 아티스트 | id |
|---|---|
| 성리 | 1~8 |
| 이찬원 | 21~28 |
| 박서진 | 41~48 |

품목을 늘려도 각 대역(20칸) 안에서만 쓰세요.

## ⚠️ 정책

굿즈 **가격은 표시 전용**입니다. 플랫폼은 금전 거래를 중개하지 않습니다.
이미지 안에 "구매하기 · 결제 · 장바구니" 같은 문구를 넣지 마세요.

# 디자인 시스템 — 발표 장표용 정리

> **MBN AI 트롯 팬덤 플랫폼**의 디자인 시스템을 발표 장표에 옮겨 담기 좋게 정리한 문서입니다.
>
> - 값은 전부 **구현체(`FE/src/styles/tokens.css`)에서 그대로 뽑은 실측값**입니다. 장표에 복사해 쓰셔도 됩니다.
> - 엔지니어링용 원본 측정 기록은 `docs/design-tokens.md`(Figma 노드별 실측), 화면 명세는 `docs/HANDOFF.md` §1 을 보세요.
> - ⚠️ Figma 원본 파일에서 **화면 노드는 현재 조회되지 않습니다**(`components` 페이지만 남음). 새 캡처가 필요하면 실행 중인 앱에서 직접 찍는 것이 정확합니다.

## 1. 한 장 요약

| 항목 | 내용 |
|---|---|
| 제품 | 트롯 스타의 공식 콘텐츠 · 팬 커뮤니티 · AI 팬 매니저를 하나로 묶은 **글로벌 트롯 팬덤 플랫폼** |
| 주 사용자 | **중장년 트롯 팬** + 해외 팬 |
| 캔버스 | **375px 모바일 단독** (데스크톱 레이아웃 없음) |
| 브랜드 컬러 | **`#F58220`** MBN 오렌지 |
| 서체 | 본문 **Pretendard** · 로고 **영도체(Yeongdo OTF Heavy)** |
| 언어 | **7개국어** (ko · en · ja · fr · es · zh · ru) |
| 시그니처 | 큰 마이크 FAB → 음성 AI 도우미 **"비엔이"** |

**한 문장:** *"메뉴를 파고들지 않고 말로 끝내는 팬덤 앱."*

## 2. 디자인 원칙 4가지

발표에서 "왜 이렇게 생겼나"를 설명할 때 쓰는 축입니다. 넷 다 **실제 설계 결정으로 이어졌습니다.**

### ① 뎁스를 줄이고 버튼을 키운다 — 중장년 사용자

주 사용자층이 중장년입니다. 3탭 셸을 **폐기**하고 랜딩 + 메인 + 기능 화면 구조로 평탄화했습니다.

- 회원가입 → **닉네임 룰렛**으로 대체 (가입은 가장 큰 이탈 지점)
- 화면 이동 → **음성 한 마디**로 대체
- 마이크 FAB **104px**, 주요 CTA 최소 높이 **48px**

### ② 색은 정보다 — 계열별로 의미를 고정

| 계열 | 색 | 의미 |
|---|---|---|
| 오렌지 | `#F58220` | 브랜드 · 사용자 행동(CTA·내 말풍선·활성 상태) |
| 인디고 | `#4F46E5` | **AI가 만든 것** (AI 분석 패널, 음성 답변, 대화방 AI 답변) |
| 빨강 | `#EF4444` | LIVE |
| 초록/빨강 | `#16A34A` / `#DC2626` | 성공 / 실패 토스트 |

> **AI를 인디고로 통일한 것이 이 시스템의 핵심 규칙입니다.** 사용자가 "이건 사람이 쓴 게 아니라 AI가 만든 것"을 색만 보고 구분합니다. 기획서 정책(AI는 스타를 사칭하지 않는다)을 시각 언어로 옮긴 장치입니다.

### ③ 장식이 아니라 상태 신호

음성 마이크 뒤 **주황 물감 번짐 이펙트**는 단계마다 속도와 확산 거리가 다릅니다(`--burst-speed` / `--burst-spread`). 화면을 읽지 않아도 "지금 듣는 중인지, 분석 중인지"를 알 수 있어야 하기 때문입니다.

### ④ 글로벌은 UI 문자열만이 아니다

7개 언어 전환 시 **댓글 국가 배지·통화 단위까지** 함께 바뀝니다. 한때 배지가 한글로 굳어 있었는데, 글로벌이 주제인 제품에서 가장 아픈 자리라 전부 i18n 키로 뺐습니다. (259키 × 7언어 parity 검증)

> 각도가 화면 종류마다 다릅니다. 장표에 배경으로 쓰실 때 이 각도를 그대로 쓰면 앱과 같은 인상이 납니다.

## 7. 핵심 컴포넌트 어법

| 컴포넌트 | 규칙 |
|---|---|
| **카드** | 흰 배경 · `radius-md(12)` · 그림자 약하게. 가로 캐러셀 260×236, 2열 그리드 164×189 |
| **상태 배지** | 모집중/마감/종료. `radius-sm` · 12px Bold |
| **진행바** | 인디고 트랙 + 오렌지 채움. **`34/40` 숫자를 항상 함께 노출** |
| **토스트** | Success / Error / Info 3종. 배경 `#111827` |
| **바텀시트** | 상단 `radius-xl(24)` · 뒤에 85% 딤. 언어 선택·음성 오버레이 공용 |
| **칩** | Default / Selected 2상태. 필터·언어 |
| **마이크 FAB** | 104px 원형 · 오렌지 · 글로우 그림자. **앱의 시그니처 요소** |

### 음성 오버레이 — 시그니처 화면

```
마스코트(시트 위로 걸침)
─────────────── 바텀시트 ───────────────
  내가 말한 문장 (회색 말풍선)
  AI 답변 (인디고 카드)
  └ 무대 영상 / 후속 행동 버튼
  이제 말씀하세요. 원하는 기능을 수행해 드립니다.
  ◉ 마이크 104px + 주황 물감 이펙트
```

**5단계 상태 머신**: `듣기 → 받아쓰기 → 분석 → 답변 → 다음 지시`
단계는 마이크 뒤 이펙트의 **속도·확산 거리**로 표현합니다.

## 8. 화면 구조 (IA)

```
랜딩 (다크 테마 · 아티스트 13명)
  └ 닉네임 룰렛 (로그인 대체 — 게스트 계정 발급)
     └ 메인 /home ── LIVE 배너 · 소식 스레드 · 큰 마이크 FAB
        ├ 소식 /feed         AI 소식 요약 + 아티스트 글 + 무대 롱폼
        ├ 방송 /broadcast    기사 · 롱폼 · 숏폼
        └ 팬공간 /fanspace   투표 배너 · 캘린더 · [공연 | 투표 | 굿즈 | 모집]
             ├ 공연 응모 (1인 1매)
             └ 참여 중인 모집 → 단체 대화방 (AI 단독 응답)

어느 화면에서든 마이크 FAB → 음성 AI 도우미 "비엔이"
```

### 장표에 넣기 좋은 대표 화면 6장

1. **랜딩** — 다크 테마 + 아티스트 그리드 (밝은 본편과 대비되는 첫인상)
2. **닉네임 룰렛** — 로그인 없는 진입
3. **메인** — 영도체 로고 + LIVE 배너 + 마이크 FAB
4. **음성 오버레이** — 마스코트 + 인디고 답변 카드 + 후속 버튼 ★핵심
5. **모집 단체 대화방** — 오렌지(나) / 인디고(AI) 말풍선 대비
6. **언어 전환 전후** — 같은 화면 한국어 ↔ English

## 9. 디자인 결정과 근거 ★발표 하이라이트

심사에서 "왜?"라는 질문이 나올 자리들입니다.

| 결정 | 근거 |
|---|---|
| **3탭 셸 폐기** | 주 사용자층이 중장년. 뎁스를 줄이고 버튼을 키웠습니다 |
| **회원가입 → 닉네임 룰렛** | 중장년에게 가입이 가장 큰 이탈 지점. 기기당 1회, 즉시 진입 |
| **AI 진입점은 마이크 FAB 단독** | 검색바 AI 모드를 없애 "말을 걸 곳"을 하나로 고정 |
| **AI 계열은 인디고로 통일** | AI 생성물임을 색으로 구분. 사칭 금지 정책의 시각적 구현 |
| **랜딩만 다크 테마** | 진입 → 팬덤 공간 전환을 하나의 연출로 |
| **이펙트 세기를 단계마다 다르게** | 장식이 아니라 상태 신호. 통일하면 진행 중인지 알 수 없습니다 |
| **음성 실행 후 화면을 이동시키지 않음** | 응모가 끝났다는 사실을 읽기도 전에 시트가 닫히면 무슨 일이 일어난 건지 알 수 없습니다. 이동은 버튼으로 사용자가 선택 |
| **응모는 「응모하기」 버튼 하나** | 1인 1매 고정. 매수 선택기를 없애 결정 지점을 줄였습니다 |
| **로고를 이미지가 아닌 웹폰트로** | 아티스트마다 글자가 달라집니다(매일찬원 / 매일서진) |
| **데스크톱 레이아웃 없음** | 디자인이 375px 모바일 단독. 범위를 지켰습니다 |

### 정책이 만든 UI (기획서에서 온 것 — 협상 대상 아님)

- AI는 **"MBN AI 도우미 비엔이"**이며 스타 본인을 사칭하지 않습니다 → AI 배지·인디고 계열
- 모임 참가비·굿즈 가격은 **표시 전용** → 모든 관련 화면에 "플랫폼은 금전 거래를 중개하지 않습니다" 고지
- 공연 응모는 **추첨 신청이지 결제가 아닙니다** → 응모 화면 고지 필수
- 장소는 **공개된 출처만**, `sourceUrl` 필수 → 성지순례 카드에 출처 표기

## 10. 접근성

- **진행바는 색만으로 정보를 전달하지 않습니다** — `34/40` 숫자를 항상 함께
- 터치 타깃 **최소 44px** — 하트·번역 아이콘은 투명 패딩으로 히트 영역 확장
- 룰렛 회전 구간은 `aria-hidden` — 스크린리더가 매 프레임 읽지 않도록
- `prefers-reduced-motion` 대응 — 이펙트를 은은한 글로우로 대체
- 마이크 권한 거부 시 **텍스트 입력 폴백** 필수
- ⚠️ **알려진 미달**: 배너 CTA `white on #F58220` 대비 약 **2.9:1** (AA 미달).
  20px Bold 기준 3:1에 근접하나 여유가 없어, 필요 시 배경을 `#E4741A`로 한 단계 낮춥니다.

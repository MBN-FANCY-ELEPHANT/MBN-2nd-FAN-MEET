## 1. 공통 셸 (탭 3화면 전용)

HOME / COMMUNITY / PLAY 세 화면이 상단부를 **완전히 공유**합니다. 상세 화면들은 `Header (Back)`만 씁니다.

```
┌─────────────────────────────┐
│ MBN AI            🌐 한국어  │  Header          (2:205)
├─────────────────────────────┤
│  HOME   COMMUNITY   PLAY    │  TabBar          (2:207)
│  🔍 검색어를 입력해주세요.    │  SearchBar       (2:206)
│  임영웅 님과의 팬덤 공간       │  StarGreeting    (2:218)
│  오늘 하루도 즐거운 하루되세요! │
│  ┌───────────────────────┐  │
│  │ {탭별 서브카피}         │  │  HeroBanner      (2:221)
│  │ {탭별 CTA}             │  │
│  └───────────────────────┘  │
├─────────────────────────────┤
│  {탭별 본문 섹션}        🎤  │  BottomSheet(2:225) + MicFab(2:234)
└─────────────────────────────┘
```

### 탭별 배너 문구 (디자인 확정값)

| 탭 | 서브카피 | CTA | 동작 |
|---|---|---|---|
| HOME | 오늘을 즐기고 싶다면? | AI 매니저와 대화하기 | 음성 AI 오버레이 열기 |
| COMMUNITY | 오늘의 플레이리스트! | 이 노래는 어떠신가요? | 음성 AI 오버레이 열기 |
| PLAY | 오늘을 즐기고 싶다면? | AI 매니저와 대화하기 | 음성 AI 오버레이 열기 |

> COMMUNITY 배너에는 **마스코트("비엔이") 일러스트**가 우측에 올라갑니다.

### 검색바

`Search Bar (Default)` / `(Active)` **2상태만** 존재합니다.
초안에 있던 `AI Default` / `AI Mode`는 **삭제됐습니다** — 검색바는 순수 텍스트 검색 전용입니다.
AI 진입점은 **마이크 FAB 단독**입니다.

### 언어 칩 (헤더 우측)

탭하면 언어 선택 Bottom Sheet(화면 2)를 엽니다. **7개 언어**:
`English` / `한국어` / `Français` / `日本語` / `Español` / `简体中文` / `Русский`
현재 선택 언어는 `--color-primary` Bold로 표시.

### MicFab

우측 하단 고정. 64×64 원형, `--color-primary`, 마이크 아이콘 32px.
탭하면 **음성 AI 오버레이**(화면 3~6)를 엽니다. 탭 3화면 모두에 존재합니다.

### 화면 3~6 — 음성 AI "비엔이" (`7:1432` → `7:1490` → `7:1548` → `7:1605`)

Bottom Sheet 오버레이 + 마스코트 일러스트로 구성된 **4단계 상태 머신**입니다.

| # | 상태 | 마스코트 | 안내 문구 | 마이크 버튼 |
|---|---|---|---|---|
| 3 | `LISTENING` | 마이크 든 비엔이 | **말씀해 주세요. 듣고 있습니다.** | 오렌지 + 글로우 |
| 4 | `TRANSCRIBING` | 마이크 든 비엔이 | 인식된 발화 실시간 표시<br>`그.. 우리 임영웅이.. 콘서트가 언제야` | 오렌지 |
| 5 | `THINKING` | 돋보기+태블릿 든 비엔이 | **검색 중…** | 회색 (비활성) |
| 6 | `ANSWERED` | (숨김) | 인디고 테두리 카드에 답변<br>`다음 콘서트는 29일로 예정되어 있습니다.` | 오렌지 (재질문 가능) |

**구현 노트**

- 4단계의 "구어체가 그대로 뜨는" 표현이 핵심 연출입니다 → **STT 중간 결과(interim result)** 가 필요합니다.
- 5단계 마이크 비활성화는 **중복 요청 차단** 역할도 합니다.
- 6단계 답변 카드는 인디고 계열 — AI 계열 UI는 전부 인디고로 통일돼 있습니다(`AI Pannal`과 동일).
- 답변에 근거가 있으면 카드 하단에 **딥링크 칩**을 붙입니다 (디자인 미표기, 골든 패스상 필요).

**응답 정책 (기획 제약)**

- 이름: **MBN AI 도우미 "비엔이"**. 스타 본인을 사칭하지 않습니다.
- 답변 범위: **MBN 방송·트롯 아티스트·플랫폼 콘텐츠(일정/기사/영상/모임/장소/팁)** 로 한정.
- 범위 밖 질문은 답하지 않고 정중히 안내합니다 (`t('chat.outOfScope')`).
- DB에 근거가 없으면 지어내지 않고 모른다고 답합니다.

## 3. 인증 — 간이 구현

**정교한 인증은 구현하지 않습니다.** 로그인/로그아웃 상태 구분만 필요합니다.

| 항목 | 방침 |
|---|---|
| 로그인 방식 | 데모 계정 **원클릭 선택** (이메일/비밀번호 폼 없음) |
| 토큰 | 단순 서명 토큰. 만료·리프레시 없음 |
| 데모 계정 | 이름 · 아바타 · **국가 배지**를 갖춘 예시 유저 3~4명 |
| 비로그인 | 콘텐츠 조회 전부 가능. 댓글 작성·좋아요·구독·모임 신청만 차단 |

댓글 화면에서 여러 국가의 유저가 보이는 것이 데모 포인트이므로,
시드 유저의 `country`를 **의도적으로 분산**시킵니다 (한국 / 미국 / 일본 / 프랑스 등).

# 배포 체크리스트 — 3명 시드 + 아티스트 이미지 반영

> 로컬은 정상 동작합니다. **배포 환경은 아직 옛 시드(임영웅 1명)** 라서
> 아래 4단계를 다 밟아야 화면이 맞습니다.

---

## 왜 배포에서 아직 안 보이는가

이미지는 **FE 가 서빙**하고, 그 이미지의 **경로 문자열은 BE DB 에** 들어 있습니다.

```
브라우저 ──GET /api/v1/contents──▶ BE   →  thumbnailUrl: "/artists/seojin/post-1.jpg"
        ──GET /artists/seojin/post-1.jpg──▶ FE (dist/artists/...)
```

- FE `public/artists/**` 는 빌드하면 `dist/artists/**` 로 그대로 복사됩니다 ✅
- `vite.config` 에 `base` 가 없어 **루트(/) 배포 전제**라 `/artists/...` 가 그대로 맞습니다 ✅
- ❌ **배포 BE 의 DB 가 아직 옛 시드**라 `"/example_thumb.png"` 를 돌려줍니다 → 기본 이미지

즉 **FE 만 다시 배포해도 안 바뀝니다.** BE DB 를 다시 심어야 합니다.

---

## 1. FE — `.env` 를 배포용으로 되돌리기 ⚠️ **가장 실수하기 쉬움**

로컬 확인을 위해 비워둔 상태입니다. **이대로 빌드하면 배포된 FE 가 자기 자신에게
`/api/...` 를 요청해서 전부 404 가 납니다.**

```bash
# FE/.env
VITE_API_BASE_URL=https://api.dgu-fallfesta.site
```

`.env` 는 gitignore 대상이라 **배포를 돌리는 머신에서 직접** 맞춰야 합니다.

## 2. FE — 빌드 & 배포

```bash
cd FE && npm run build     # dist/artists/** 에 이미지가 포함되는지 확인
ls dist/artists/*/         # profile.png · post-1.* · concert.* 가 보여야 합니다
```

## 3. BE — 새 jar 빌드

`data.sql` 이 바뀌었으므로 jar 를 다시 만들어야 합니다.

```bash
cd BE && ./gradlew clean build
```

## 4. BE — DB 재적재 ⚠️ **이 단계를 빼먹으면 아무것도 안 바뀝니다**

`prod` 프로파일 기본값이 이렇습니다.

```yaml
ddl-auto: ${DB_DDL_AUTO:update}    # 기존 행을 지우지 않음
sql.init.mode: ${DB_INIT_MODE:never}   # data.sql 을 실행하지 않음
```

**그래서 jar 만 새로 올리고 재시작해도 DB 는 옛 데이터 그대로입니다.**

### 4-1. 기존 데이터 비우기

⚠️ **파괴적입니다.** 실제 사용자가 남긴 응모·모임신청·댓글·좋아요가 함께 지워집니다.
데모 데이터뿐이라면 문제없지만, 심사 중 쌓인 기록을 남기고 싶다면 먼저 백업하세요.

```sql
-- FK 역순. PostgreSQL 기준.
TRUNCATE TABLE
  comment_translation, comment, content_place,
  ai_analysis_item, ai_analysis,
  concert_entry, gathering_application, reaction, subscription,
  chat_message, chat_session,
  content, gathering, place, tip, schedule,
  artist_stage, channel, app_user, star
RESTART IDENTITY CASCADE;
```

### 4-2. 한 번만 시드 주입

```bash
DB_INIT_MODE=always java -jar build/libs/*.jar
```

### 4-3. **환경변수를 되돌리기** ⚠️

```bash
DB_INIT_MODE=never   # (또는 변수 제거)
```

되돌리지 않으면 **재시작할 때마다 시드가 다시 INSERT 되어 PK 충돌로 기동이 실패**합니다.

## 5. 확인

```bash
API=https://api.dgu-fallfesta.site

# 스타 3명
for id in 1 2 3; do curl -s "$API/api/v1/stars/$id" | head -c 120; echo; done

# 이미지 경로가 /artists/... 로 나오는가
curl -s "$API/api/v1/contents?starId=3&type=POST&size=4" | grep -o '"thumbnailUrl":"[^"]*"'

# 영상 썸네일이 유튜브로 나오는가
curl -s "$API/api/v1/contents?starId=3&type=VIDEO&size=4" | grep -o '"thumbnailUrl":"[^"]*"'
```

**브라우저에서**

- [ ] 랜딩에서 박서진을 고르면 **박서진 데이터**가 뜨는가 (성리가 아니라)
- [ ] 소식 스레드에 박서진 프로필·`post-1.jpg` 가 뜨는가
- [ ] 롱폼 카드에 유튜브 썸네일이 뜨는가
- [ ] 이미지가 안 뜨면 → **FE 를 다시 배포했는지** 확인 (`/artists/...` 는 FE 가 서빙)
